# 12 — هيكل تجربة المستخدم

## 12.1 مبادئ

1. **الفني في الشارع، ليلًا، بقفازات، على رافعة، بهاتف متوسط، بإنترنت ضعيف.** كل قرار تصميم يُختبر على هذا السيناريو.
2. **خطوة واحدة في الشاشة.** زر رئيسي واحد كبير في الأسفل (منطقة الإبهام). لا قوائم منسدلة طويلة.
3. **النظام يتذكر ويقترح:** المواد المتوقعة حسب التشخيص، قيم آخر أصل مسجل، الفحص الافتراضي.
4. **الحالة واضحة دائمًا:** شريط أعلى يوضح: متصل/غير متصل · "3 عناصر بانتظار الإرسال" · "صورتان قيد الرفع".
5. **الأخطاء بلغة بشرية وحل واضح:** "لم نتمكن من قراءة الملصق — أدخل الرقم المكتوب تحته" لا "QR decode error".
6. **العربية أولًا:** RTL كامل، مصطلحات ميدانية حقيقية (تُراجع مع الفنيين — "درايفر" قد يكون أوضح من "مشغل كهربائي")، الأرقام الغربية افتراضيًا (0-9) مع خيار، التاريخ الميلادي مع عرض هجري اختياري.
7. **إمكانية الوصول:** نص ≥ 16sp، أزرار ≥ 56dp، تباين عالٍ، **وضع ليلي** (الشاشة الساطعة ليلًا تعمي الفني وتستنزف البطارية)، اهتزاز لتأكيد الالتقاط.
8. **ميزانية الوقت:** أمر عمل روتيني ≤ 3 دقائق تفاعل إضافي (يُقاس في التجربة بتسجيل زمن كل خطوة).

## 12.2 التطبيق الميداني (Mobile)

### خريطة الشاشات

```
[تسجيل الدخول + تسجيل الجهاز (مرة واحدة)]
      │
[القفل المحلي: بصمة / PIN]
      │
┌─────┴──────────── التبويبات السفلية (3 فقط) ────────────┐
│  مهامي            │  مسح          │  حسابي                │
└──────────────────────────────────────────────────────────┘

مهامي
 ├─ قائمة: الأولوية (لون + نص)، رمز الأصل، العنوان المختصر، المسافة، حالة المزامنة
 └─ فتح المهمة ─► [معالج أمر العمل — 7 خطوات مع شريط تقدم]
       1. الوصول      : "امسح الملصق" (كاميرا مباشرة) · "أدخل الرقم يدويًا"
       2. قبل العمل   : صورتان — إطار إرشادي "أظهر الملصق" في الأولى
       3. التشخيص     : شبكة أيقونات كبيرة (6–10 خيارات) + ملاحظة صوتية→نص (اختياري لاحقًا)
                        زر "لا يوجد عطل" / "الأصل غير موجود" / "يحتاج فريقًا آخر"
          [ابدأ العمل] ← زر أخضر كبير
       4. المواد      : قائمة مقترحة من عهدتي (+ / −) · مسح الرقم التسلسلي للقطع الغالية
                        "القطعة القديمة معي" ✓ + صورة
       5. الفحص       : بطاقات نعم/لا كبيرة، واحدة تلو الأخرى
       6. بعد العمل   : صورتان + صورة الاختبار (العمود مضيء)
       7. المراجعة    : ملخص قابل للتعديل قبل الإرسال
          [إرسال للمراجعة]
       ─ في أي خطوة: [إيقاف مؤقت — بانتظار قطع/وصول/سلامة]

مسح (نقطة دخول سريعة)
 ├─ مسح أي ملصق → بطاقة الأصل (الحالة، آخر صيانة، المهام المفتوحة عليه)
 │     └─ [الإبلاغ عن عطل] (بلاغ سريع: صورة + فئة)
 ├─ [جولة تفقد] (للمفتش): وضع متواصل — مسح → "يعمل / لا يعمل / تالف" → التالي
 └─ [تسجيل أصل جديد] (للمسجّل فقط)

حسابي
 ├─ عهدتي: الأرصدة · استلامات بانتظار التأكيد · قطع تالفة بانتظار التسليم · ملصقاتي (للمسجّل)
 ├─ طلب مواد
 ├─ المزامنة: الطابور، الأخطاء، "أرسل الآن"
 └─ الإعدادات: الوضع الليلي، رفع الصور عبر Wi-Fi فقط، اللغة
```

### تفاصيل حرجة

- **الكاميرا:** شاشة التقاط داخل التطبيق فقط؛ لا زر معرض. معاينة بعد الالتقاط مع "إعادة" (الصورة المعادة تُحفظ كـ `superseded` محليًا ولا تُرسل — **قرار:** في Phase 1 لا نرسل الصور المعادة قبل الحفظ؛ نرسل فقط ما حُفظ. الصور المحفوظة ثم المستبدلة تُرسل كـ superseded).
- **الإرشاد البصري:** إطار شفاف على الكاميرا يوضح ما يجب أن يظهر ("الملصق هنا"، "العمود كاملًا").
- **لا يمكن تجاوز خطوة إلزامية**، لكن الزر يوضح بالضبط ما الناقص.
- **التسجيل الأول للأصل:** قيم افتراضية من آخر أصل، ولوحة أرقام كبيرة.
- **الأداء:** بدء التطبيق < 3 ثوانٍ على جهاز بـ 3GB RAM؛ فتح الكاميرا < 1 ثانية؛ القوائم افتراضية (Virtualized).

## 12.3 لوحة الويب

### تخطيط عام

- شريط جانبي (يمين في RTL) بالأقسام حسب الدور فقط — **لا يرى المستخدم ما لا يملك صلاحيته**.
- الصفحة الرئيسية لكل دور = **"ما الذي يحتاجني الآن؟"** (Inbox)، لا لوحة رسوم.

### حسب الدور

| الدور | الصفحة الرئيسية | الصفحات |
|---|---|---|
| **مشرف** | طابور: بلاغات للفرز · أوامر بانتظار المراجعة · متأخرة · حجر المزامنة | لوحة إسناد (خريطة + قائمة فنيين وأحمالهم) · شاشة المراجعة |
| **معتمد أصول** | طابور التسجيلات حسب المخاطرة | شاشة الاعتماد السريع (اختصارات لوحة مفاتيح) |
| **أمين مخزن** | طلبات للصرف · إرجاعات وقطع تالفة للاستلام · جرد مستحق | الأرصدة · الحركات · جلسة جرد |
| **مدير قسم** | "8 أسئلة" (انظر أدناه) + موافقاتي | لوحة المؤشرات · الخريطة التشغيلية · تقارير |
| **مدقق** | إشارات مفتوحة · حالات تدقيق عشوائي · Break Glass للمراجعة | سلسلة الأدلة · سجل التدقيق · التحقق من السلسلة · تحليل المراجعين (Phase 2) |
| **مدير نظام** | المستخدمون · الأجهزة · طلبات الأدوار | القوالب · أنواع الأصول · الإعدادات |

### شاشة المراجعة (الأهم للمشرف)

```
┌───────────────────────────────┬──────────────────────────────┐
│ الأدلة: قبل ⟷ بعد جنبًا لجنب  │ الملخص                        │
│ (تكبير، الـ Tag مُبرز)         │ الأصل، التشخيص، المدة         │
│                               │ المواد (مقابل المتوقع)         │
│ الخريطة المصغرة: الأصل ⊙       │ الفحص (✓/✗)                   │
│ وموقع الالتقاط ● + دائرة الدقة │ درجة الحضور (مفصلة)            │
│                               │ ⚠ الإشارات (بشرح)              │
│ الخط الزمني للمهمة             │ الفرق عن التقديم السابق        │
├───────────────────────────────┴──────────────────────────────┤
│  [اعتماد]   [إرجاع — ما الناقص؟]   [تصعيد]                    │
└──────────────────────────────────────────────────────────────┘
```

زر الاعتماد يتعطل حتى تُرفع كل الأدلة وتُفتح (يُسجل أن المراجع فتح الصور — مؤشر لا يمنع).

### لوحة المدير — الأسئلة الثمانية

كل سؤال بطاقة برقم واحد واتجاه، وتنقر للتفاصيل:

| السؤال | البطاقة |
|---|---|
| ما المعطل؟ | أصول معطلة الآن (حسب المنطقة) + خريطة |
| ما المتأخر؟ | أوامر تجاوزت SLA |
| ما المكلف أكثر من اللازم؟ | أعلى 10 أصول/طرازات تكلفة (12 شهرًا) |
| ما الذي يتكرر عطله؟ | أصول بتوصية فحص شامل |
| ما الذي يحتاج استبدالًا؟ | توصيات مراجعة الاستبدال (Phase 2) |
| ما المخزون الذي ينفد؟ | تحذيرات المخزون |
| أين الشذوذ؟ | عدد الإشارات المفتوحة حسب الخطورة (دون أسماء أشخاص) |
| ما الذي ينتظر موافقتي؟ | عدد + أقدم طلب |

### الخريطة التشغيلية

- MapLibre؛ طبقات: الأصول (لون حسب الحالة التشغيلية)، البلاغات المفتوحة، أوامر العمل، المناطق.
- Clustering؛ فلاتر (النوع، الحالة، المنطقة، الدائرة)؛ النقر → بطاقة الأصل.
- **ليست GIS:** لا تحرير هندسي متقدم، لا تحليل مكاني حر، لا طبقات مستوردة عشوائية في MVP.

## 12.4 النصوص والمصطلحات

قاموس مصطلحات موحد (`glossary.ar.json`) يُراجع مع المستخدمين، مثل:

| المفهوم | النص العربي | لا نستخدم |
|---|---|---|
| Work Order | أمر عمل | تذكرة، طلب |
| Issue | بلاغ | مشكلة، شكوى |
| Flag | ملاحظة تدقيق / شذوذ للمراجعة | مخالفة، اشتباه |
| Custody | عهدتي | مخزوني |
| Core Return | تسليم القطعة التالفة | |
| Evidence | صور التوثيق | أدلة (في الواجهة الميدانية — كلمة "أدلة" توحي بالاتهام) |

الملاحظة الأخيرة مقصودة: **اللغة في الواجهة الميدانية لا تستخدم مفردات جنائية.**

## 12.5 التحقق من التصميم

- نماذج أولية (Figma أو نموذج قابل للنقر) **تُختبر مع 3–5 فنيين حقيقيين في الشارع** قبل البناء (Phase 0).
- قياس زمن كل خطوة في التجربة الميدانية (Telemetry بلا بيانات شخصية).
- اختبار على أرخص جهاز Android يتوقع أن يستخدمه الفنيون.
